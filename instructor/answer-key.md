# แนวคำตอบและจุดตรวจ

## บท 01

Git ทำงานจัดการเวอร์ชันบนเครื่องได้แม้ไม่มีเครือข่าย GitHub เป็นบริการ Remote และ Collaboration ส่วน Desktop เป็นโปรแกรมหน้าต่างสำหรับงาน Git เก็บไฟล์ชื่อเดิมพร้อมประวัติช่วยอ่านว่าผู้ใดเปลี่ยนอะไร เพราะเหตุใด

## บท 02

Public ให้ผู้อื่นอ่านได้แต่ไม่ให้ทุกคน Push Private ต้องมีสิทธิ์จึงอ่านได้ README ควรตอบว่าโปรเจกต์คืออะไรและเริ่มอ่านตรงไหน ตรวจ Owner และ Visibility จาก Repository จริง

## บท 03

Preview ตรวจผลที่ผู้อ่านเห็น Diff ตรวจขอบเขตที่จะบันทึก ไฟล์ที่ลบยังอยู่ในประวัติ Commit เดิม รวมงานไม่เกี่ยวกันทำให้ตรวจ ย้อน หรือระบุสาเหตุยากขึ้น ตรวจลิงก์จาก README ไม่ใช่ดูชื่อเส้นทางอย่างเดียว

## บท 04

Save ไม่สร้าง Commit ส่วน Commit บนเครื่องยังไม่ Push Fetch อัปเดตข้อมูล Remote โดยไม่รวมเข้าไฟล์ของ Branch ที่ทำงาน ต้อง Pull เพื่อรับเข้า Local branch ตรวจว่าอยู่ Repository/Branch ที่ถูก ไม่มีงานค้าง และเว็บมี Commit ที่ Push แล้ว

## บท 05

Publish ส่ง Branch ไป Remote แต่ไม่ Merge การสร้าง Branch จากฐานที่ผิดอาจพางานอื่นติดมาด้วย การอัปเดต main ก่อนเริ่มลดความต่างที่ต้องแก้ภายหลัง Checkpoint ต้องเห็นไฟล์ใน Branch งานแต่ไม่เห็นใน main ก่อนบท 06

## บท 06

Pull อัปเดต Local branch ส่วน PR เสนอการ Merge และเปิดพื้นที่ Review ชื่อ PR ไม่แสดงสิ่งที่เปลี่ยนทั้งหมดจึงต้องอ่าน Diff Merge บนเว็บไม่แก้สำเนาบนเครื่องจน Fetch/Pull ผู้เขียน Approve PR ตนเองไม่ได้ ให้คู่ฝึก Review จริง

## บท 07

แก้คนละไฟล์มัก Merge ได้อัตโนมัติ แต่การลบ/เปลี่ยนชื่อและกรณีอื่นอาจขัดกัน การเลือกฝั่งโดยไม่อ่านอาจทิ้งงานที่ต้องใช้ ผลสุดท้ายต้องเป็น `Workshop title: GitHub Hands-On for Beginners` และไม่มี markers

Revert สร้าง Commit ย้อนการเปลี่ยนแปลงโดยเก็บ Commit เดิม การ Revert รหัสผ่านไม่ทำให้รหัสผ่านหายจากประวัติ ต้องยกเลิก/เปลี่ยน Secret และจัดการประวัติตามคำแนะนำผู้ดูแล

## บท 08

Issue ตอบว่าจะทำอะไรและเสร็จเมื่อใด PR แสดงสิ่งที่เปลี่ยนให้ตรวจ เกณฑ์รับงานช่วยลดการตีความต่างกัน `Closes #N` ต้องอ้างเลขจริงใน PR description และ Merge เข้า default branch จึงปิด Issue ตามกิจกรรมนี้

## หลักฐานที่รับได้

ลิงก์ Commit/PR/Issue ที่เปิดได้มีน้ำหนักกว่าภาพหน้าจออย่างเดียว ประวัติ Repository แต่ละคนไม่จำเป็นต้องมี SHA หรือเลข Issue เหมือนตัวอย่าง ตรวจพฤติกรรมและเหตุผล ผู้เรียนที่ดู Demo ต้องระบุว่าไม่ได้ทำเอง
