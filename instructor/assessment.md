# เกณฑ์ประเมิน · 100 คะแนน

| ด้าน | คะแนนเต็ม | หลักฐานสำหรับคะแนนเต็ม |
|---|---:|---|
| Repository และเอกสาร | 20 | README อธิบายได้ มีภาพ ลิงก์ใช้งานได้ และจัดไฟล์เป็นระบบ |
| Commits และการตรวจ Diff | 15 | แยกงานเหมาะสม Message สื่อความหมาย และอธิบาย Diff จริงได้ |
| Branch/PR/Review | 25 | Base/Compare ถูก มีข้อคิดเห็นจากเพื่อน ปรับตามผล Review และ Merge สำเร็จ |
| Conflict และ Revert | 15 | แสดงเหตุขัดกัน ผลแก้สุดท้าย และ Commit เดิม/Commit ย้อนที่ตรวจได้ |
| Issue และงานครบวงจร | 15 | เกณฑ์รับงานตรวจได้ เชื่อม PR และ Issue ปิดหลังงานเสร็จ |
| การอธิบายและสะท้อนผล | 10 | แยก Save/Commit/Push/Pull/PR และบอกปัญหาที่แก้ด้วยตนเอง |

แต่ละด้านให้เต็มเมื่อหลักฐานครบ ให้ประมาณครึ่งหนึ่งเมื่อทำได้บางส่วนหรืออธิบายไม่ได้ และให้ศูนย์เมื่อไม่มีหลักฐานหรือยังไม่ได้ทำ ปรับคะแนนย่อยตามขอบเขตที่สำเร็จและระบุเหตุผลประกอบ

การวัด Desktop ให้ดูการส่ง/รับงานและ Current Branch จริงร่วมกับ Commit บนเว็บ ผู้เรียนเส้นทางเว็บไม่ควรถูกระบุว่าผ่าน Desktop จากภาพหรือ Demo ของผู้อื่น หากสอนแบบเว็บอย่างเดียว ให้ประกาศเกณฑ์ปรับก่อนเรียน เช่น ประเมินการอธิบาย Revert จาก Demo แทนการปฏิบัติ และบันทึกผลเป็นความเข้าใจ ไม่ใช่ทักษะ Desktop

ไม่ให้คะแนนจากจำนวน Commit อย่างเดียว และไม่จำเป็นต้องใช้ชื่อ Branch/Commit ตรงตัวอย่างหากการทำงานถูกต้อง
