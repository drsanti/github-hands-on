# ภาพประกอบ

[project-icon.svg](images/project-icon.svg) เป็นภาพตัวอย่างที่สร้างสำหรับกิจกรรมนี้ ให้นำไปบันทึกเป็น `assets/project-icon.svg` ใน Repository ฝึกของตนเอง แล้วใช้ Markdown:

```markdown
![Project icon](assets/project-icon.svg)
```

ในหลักสูตรนี้จัดภาพไว้ใน `assets/images/` แต่ในโปรเจกต์ฝึกใช้ `assets/` เพื่อให้เส้นทางสั้น ตรวจชื่อไฟล์ ตัวพิมพ์เล็ก/ใหญ่ และตำแหน่งสัมพันธ์กับไฟล์ Markdown ทุกครั้ง

หากเพิ่มภาพหน้าจอ ให้ครอปส่วนข้อมูลลับออก ใส่คำอธิบายภาพ และตั้งชื่อที่บอกบทและขั้นตอน ไม่ใช้ภาพแทนขั้นตอนข้อความเพียงอย่างเดียว
