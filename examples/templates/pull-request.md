## สิ่งที่เปลี่ยน

- ระบุไฟล์และพฤติกรรม/เนื้อหาที่เปลี่ยน

## เหตุผล

อธิบายปัญหาที่การเปลี่ยนแปลงนี้แก้

## วิธีตรวจและผล

- [ ] อ่าน Diff แล้ว
- [ ] เปิด Markdown Preview แล้ว
- [ ] ทดลองลิงก์หรือภาพที่เปลี่ยนแล้ว

## Issue ที่เกี่ยวข้อง

หากมี Issue ให้แทนบรรทัดนี้ด้วย Closes #N โดยใช้เลข Issue จริง และตั้ง Base เป็น default branch

## จุดที่อยากให้ช่วย Review

ระบุจุดที่ต้องการข้อเสนอแนะ
