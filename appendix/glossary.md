# คำศัพท์ Git/GitHub

| คำ | ความหมายที่ใช้ในหลักสูตร |
|---|---|
| Repository / Repo | โปรเจกต์ที่จัดการไฟล์และประวัติด้วย Git |
| Working directory | ไฟล์ที่กำลังเห็นและแก้บนเครื่อง |
| Commit | จุดบันทึกการเปลี่ยนแปลง พร้อม Message และรหัส |
| SHA | รหัสระบุ Git object ใช้อ้างอิง Commit/ไฟล์อย่างเฉพาะเจาะจง |
| Diff | ความต่างระหว่างเนื้อหาสองเวอร์ชัน |
| Branch | ชื่อที่ชี้ไปยังเส้นทาง Commits |
| main | ชื่อ Branch หลักที่เลือกใช้ในกิจกรรม ไม่ใช่คำสงวนบังคับ |
| Default branch | Branch เริ่มต้นของ Repository กิจกรรมนี้ใช้ main |
| Local | Repository บนเครื่อง |
| Remote | Repository อีกแห่งที่ติดต่อกัน เช่น บน GitHub |
| origin | ชื่อ Remote ที่มักตั้งอัตโนมัติเมื่อ Clone ไม่ใช่ชื่อ Branch |
| Clone | คัดลอก Repository พร้อมประวัติลงเครื่องและเตรียม Remote |
| Push | ส่ง Commits ไป Remote |
| Fetch | รับข้อมูล Remote โดยยังไม่รวมเข้า Branch ที่ทำงาน |
| Pull | รับแล้วรวมการเปลี่ยนแปลง Remote เข้า Local branch ตามการตั้งค่า |
| Merge | รวมประวัติการทำงานจากอีก Branch |
| Pull Request / PR | ข้อเสนอรวมงานและพื้นที่สนทนา/Review บน GitHub |
| Base / Compare | Branch ปลายทาง / Branch ที่เสนอการเปลี่ยนแปลง |
| Review | ตรวจเนื้อหาและให้ผล Comment/Approve/Request changes |
| Conflict | Git ต้องให้คนช่วยตัดสินใจรวมการเปลี่ยนแปลง |
| Revert | สร้าง Commit ใหม่ย้อนผล Commit เดิม |
| Issue | รายการปัญหา งาน หรือข้อเสนอ |
| Collaborator | ผู้ที่ได้รับสิทธิ์ทำงานใน Repository |
| Fork | สำเนา Repository ภายใต้บัญชีอื่นบน GitHub ที่ยังเชื่อมโยงกับต้นทาง |
| Markdown | รูปแบบข้อความสำหรับหัวข้อ รายการ ลิงก์ และเอกสาร |
