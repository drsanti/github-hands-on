# แผนผังเอกสารและการตั้งชื่อ

## หลักสูตรนี้กับโปรเจกต์ของนักศึกษา

| Repository | หน้าที่ | ไฟล์ตัวอย่าง |
|---|---|---|
| `github-hands-on` | เอกสารหลักสูตร อ่านและนำตัวอย่างไปใช้ | `lessons/05-branches/README.md` |
| `my-first-project` ของแต่ละคน | พื้นที่ฝึก Commit/Branch/PR | `README.md`, `projects/first-project.md` |

ไม่ต้อง Copy หลักสูตรทั้งหมดลงโปรเจกต์ฝึก ใช้ [Starter project](../examples/starter-project/README.md) เมื่อบทเรียนระบุเท่านั้น

## หลักการจัดไฟล์

| โฟลเดอร์ | หลักการ |
|---|---|
| `lessons/01-.../README.md` ถึง `08-.../README.md` | เลขสองหลักเรียงลำดับ แต่ละบทมีหน้าเดียวเป็นจุดเริ่ม |
| `worksheets/01-...md` ถึง `08-...md` | เลขตรงกับบท บันทึกหลักฐานแยกจากคำอธิบาย |
| `examples/starter-project/` | ไฟล์ที่นำไปสร้างโปรเจกต์ฝึก |
| `examples/conflict/` | เนื้อหาเริ่มต้นเพื่อสร้าง Conflict แบบทำซ้ำได้ |
| `examples/templates/` | ข้อความแม่แบบ ให้นำไปใส่ Issue/PR ของโปรเจกต์ฝึก |
| `assets/images/` | ภาพประกอบเอกสารหรือภาพตัวอย่าง |
| `instructor/` | เฉลยและเกณฑ์ประเมิน เปิดอ่านได้ ไม่ใช่ข้อสอบลับ |
| `appendix/` | เรื่องค้นดูระหว่างทำงาน ไม่จำเป็นต้องอ่านตามลำดับ |

ตั้งชื่อไฟล์ภาษาอังกฤษตัวพิมพ์เล็ก คั่นคำด้วย `-` ใช้ `.md` สำหรับบทเรียน ใช้ลิงก์แบบ Relative เพื่อให้อ่านได้ทั้งบน GitHub และเมื่อ Clone มา หลีกเลี่ยงไฟล์ชื่อ `final-final-v2` เพราะ Commit history ทำหน้าที่เก็บเวอร์ชันอยู่แล้ว

ภาพหน้าจอในอนาคตใช้ชื่อ เช่น `04-desktop-commit.png` เก็บใน `assets/images/` ใส่คำอธิบายภาพและไม่แสดง Token หรือข้อมูลส่วนตัว
