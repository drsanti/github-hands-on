# เตรียมความพร้อม

## สิ่งที่ต้องมี

- บัญชี GitHub ที่เข้าสู่ระบบและยืนยันอีเมลแล้ว
- เว็บเบราว์เซอร์และอินเทอร์เน็ต
- [GitHub Desktop](https://desktop.github.com/) และโปรแกรมแก้ข้อความ เช่น [VS Code](https://code.visualstudio.com/)
- โฟลเดอร์เก็บงาน เช่น `Documents/GitHub` และพื้นที่สำหรับโปรเจกต์ฝึก
- เพื่อนหนึ่งคนสำหรับบท Review สามารถฝึกส่วนอื่นคนเดียวได้

GitHub Desktop รองรับ Windows และ macOS ตาม [ข้อกำหนดปัจจุบัน](https://docs.github.com/en/desktop/overview/supported-operating-systems-for-github-desktop) ตรวจข้อกำหนดก่อนติดตั้ง ผู้ใช้ Linux หรือระบบรุ่นเก่าดูเส้นทางเว็บด้านล่าง

## ตั้งค่า Desktop

1. ติดตั้งและเปิด GitHub Desktop เลือกเข้าสู่ระบบ GitHub.com
2. ยืนยันผ่านเบราว์เซอร์ ตรวจว่าใช้บัญชีเดียวกับเว็บไซต์
3. ตั้งชื่อและอีเมลผู้สร้าง Commit ใน Settings/Preferences → Git ใช้อีเมลที่ยืนยันแล้วหรืออีเมล `noreply` ที่ GitHub แสดงใน Settings → Emails หากต้องการลดการแสดงอีเมลส่วนตัว
4. เลือกโปรแกรมแก้ข้อความใน Settings/Preferences → Integrations → External editor
5. เตรียมโฟลเดอร์ `Documents/GitHub` อย่าสร้าง Repository ฝึกซ้อนอยู่ใน Repository หลักสูตร

การตั้งชื่อผู้สร้าง Commit เป็นข้อมูลระบุตัวผู้เขียน ไม่ใช่การเข้าสู่ระบบและไม่ให้สิทธิ์ Push แทนการยืนยันบัญชี

## ก่อนเริ่มกิจกรรม

- [ ] เปิดหน้าบัญชี GitHub ของตนเองได้
- [ ] Desktop แสดงบัญชีที่ถูกต้อง หรือเลือกเส้นทางเว็บแล้ว
- [ ] โปรแกรมแก้ไขบันทึกไฟล์ `.md` ได้
- [ ] ใช้ชื่อหรือชื่อเล่นที่ยินดีเผยแพร่ ไม่ใส่รหัสนักศึกษา เบอร์โทร หรือข้อมูลลับในไฟล์ฝึก

## เรียนผ่านเว็บไซต์อย่างเดียว

บท 01–03 ทำผ่านเว็บตามปกติ บท 04 ให้ศึกษาความหมาย Local/Remote จาก Demo และบันทึกว่าไม่ได้ฝึก Desktop จากนั้นทำบท 05–08 โดย:

1. ใช้เมนู Branch บนหน้า Code สร้าง Branch ใหม่จาก `main`
2. เปิดไฟล์ → Edit และ Commit changes โดยตรวจชื่อ Branch ก่อนยืนยัน
3. ใช้ Pull requests → New pull request เปรียบเทียบ `main` กับ Branch ที่แก้
4. ใช้ตัวแก้ Conflict บนเว็บในบท 07 สำหรับกรณีข้อความง่าย ๆ นี้
5. กิจกรรม Revert ใน Desktop ใช้เครื่องผู้สอน/เครื่องที่รองรับ หากไม่มีให้ส่งการอธิบายจาก Demo และระบุชัดว่ายังไม่ได้ทำด้วยตนเอง

การใช้เว็บไม่ได้เป็นหลักฐานว่าได้ฝึก Clone, Push และ Pull บนเครื่อง ผู้สอนประเมินตามเส้นทางที่เลือก

## ข้อตกลงของโปรเจกต์ฝึก

ใช้ Repository ของผู้เรียนชื่อ `my-first-project` และ default branch ชื่อ `main` ถ้าบัญชีตั้งชื่อเริ่มต้นต่างออกไป ให้เลือกเปลี่ยนเป็น `main` ตั้งแต่ตอนสร้าง หรือแทนชื่อให้ตรงกันตลอดกิจกรรม
