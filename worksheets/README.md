# ใบงานและหลักฐานการเรียน

Copy ข้อความใบงานไปบันทึกในไฟล์ของตนเอง หรือระบบส่งงานที่ผู้สอนกำหนด ไม่ต้องเปิด Issue/PR ใน Repository หลักสูตรเพื่อส่งคำตอบ

ใช้ชื่อเล่น/ชื่อบัญชีและลิงก์ผลงาน ไม่ใส่ข้อมูลส่วนตัวที่ไม่จำเป็น หาก Repository เป็น Private ให้สิทธิ์ผู้สอนก่อนส่ง ลิงก์อย่างเดียวไม่เพิ่มสิทธิ์

| [05](05-branches.md) | แยก Branch |

ไม่ต้องสร้างภาพหน้าจอทุกขั้นตอน ใช้ลิงก์ไฟล์ Commit, PR และ Issue เป็นหลัก ภาพหน้าจอใช้เฉพาะสิ่งที่ลิงก์ไม่แสดง เช่น Current Branch และ Changes บนเครื่อง
